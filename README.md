# Dashboard Kewangan

Financial Tracker & Report peribadi: Ringkasan (net worth), Aset, Bisnes, Loans dan Report bulanan.
Satu fail HTML (`index.html`), mobile-first, dark/light mode.

- Data asal tertanam dalam `index.html` (setakat 1 Nov 2026). Perubahan yang dibuat dalam page disimpan dalam browser (localStorage) sahaja.
- Backup: butang muat turun di kanan atas → Copy JSON / Import JSON.
- Cloud sync hanya berfungsi dalam versi artifact di claude.ai.

Dihoskan dengan GitHub Pages.
